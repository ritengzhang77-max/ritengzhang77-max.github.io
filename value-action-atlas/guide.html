How to move from one value and action-choice question to ranked features and feature-level evidence.

Purpose

Inspect Task2 action-choice evidence without treating one score as a complete explanation.

The browser organizes features associated with which concrete action the model chooses. Use the filters to narrow the ranked rows, then select a feature to inspect its interpretation, validation fields, and concrete examples.

  1. 1. Choose a value and question.Select one of the 56 values, then choose the observational or causal evidence stage you want to inspect.
  2. 2. Narrow the rows.Use direction, site, interpretation, artifact, and search filters. Top K controls how many ranked rows appear.
  3. 3. Open a feature.Select a row and read the detail panel, examples, and causal fields before drawing a substantive conclusion.

Control reference

What each control does

Value
Selects one value item and its value family. The production browser contains 56 values.
Direction
Switches between features ranked for Option1 and Option2 support.
Site
Restricts the activation location, such as the answer-choice token, option spans, action sites, or pre-answer site.
Category
Filters the broad interpretation class: semantic-ish, mixed/uncertain, scaffold/syntax, or format/scaffold.
Manual Interest
Filters Hermes/manual-review judgments, including strong or moderate semantic interest, confound/control, not semantic, and unclear.
Moral Primary
Filters the moral-primary audit tier, from stronger moral-semantic candidates through global/dataset semantic, scaffold/control, and low-priority uncertain tiers.
Artifact
Shows or hides rows flagged by artifact checks.
Top K
Controls the number of ranked feature rows shown after filtering.
Search
Matches a feature ID or words in the feature explanation.

Reading the result

Ranked rows, summary cards, and feature detail

Summary cards

Family names the value family; Examples reports the value-level sample count; Variant B shows response balance; Q3/Q4 reports available causal bundles.

Top Features

Each row reports rank, feature ID, score, rate information, selected sites, manual/Hermes interpretation, and moral-primary audit label. Select a row to open it.

Feature Detail

The detail panel exposes the selected feature's score, rates, bundle information, rank fields, interpretation labels, artifact warnings, and available support level.

Examples and causal evidence

Concrete activation/corpus examples help check what the feature responds to. Q3/Q4 fields are the causal lane; observational ranking alone is not proof of mechanism.

Interpretation rule: read the semantic explanation, artifact warning, examples, and causal fields together. A high observational score is a discovery signal—not sufficient causal evidence by itself.
